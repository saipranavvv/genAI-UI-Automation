A BDD feature file describes a specific user behavior in a simple, human-readable format called Gherkin. The file is structured into a `Feature` and one or more `Scenario`s, each with a series of steps.

The keywords you need to recognize are:

- **Feature:** Describes the overall functionality being tested.
- **Scenario:** A specific example of a behavior within the feature.
- **Given:** The initial state or context of the system (the "precondition").
- **When:** The action the user performs.
- **Then:** The expected outcome or result of the action.
- **And/But:** Used to add more steps to a `Given`, `When`, or `Then` statement.
